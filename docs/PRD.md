# 带薪摸鱼模拟器 — PRD V1.0（已确认）

确认基准：用户于 2026-11-11 确认的 PRD V1.0 第二版。
**需求变更（2026-11-12）：用户明确决定取消「带薪开会」功能，不再纳入开发、统计、成就或每日结算。** 其他需求仍按原确认稿执行。

## 产品定位
轻量的打工人趣味工资模拟工具：按输入薪资与计薪时间估算累计工资，记录行为与时间，根据作息主动提醒，提供趣味文案及成就。显示的是**模拟收入**，不是银行到账数据。

## 已锁定的决定
- 品牌主题：奶油薄荷绿。背景 `#F5FAF5`，白色卡片 `#FFFFFF`，浅绿 `#DFEFE4`，主绿 `#297A5B`，深字 `#264E3B`，杏色 `#E9B77D`。
- 网页版：独立的响应式完整网站，包含工作台、活动统计、成就中心、设置。电脑/平板/手机可用。
- 桌面小组件：独立约 400 × 100 CSS px 的窗口，厕所/摸鱼/学习只显示 Icon；外链 Icon 在浏览器打开完整网页，不在窗口内展开。桌面版后续通过 Tauri 2 制作，支持置顶、托盘、快捷键等。
- 工资口径：首次初始化默认**税前**；支持手动改成税后到手，不在 V1.0 自动推算税社保。
- 加班：基本工资、加班收入**分开统计，合计展示**，不重复计入；可以没有加班费、有额外加班费、暂不确定。用户自定义倍率或固定加班时薪，不根据地区法律自动推断。
- 技术：Vue 3、TypeScript、Tailwind CSS 4、Vite、Pinia；本地优先，未来 Tauri 2。
- 商业方向：免费网页版验证需求；付费桌面 Pro 和皮肤等在后续版本探索。

## 首次使用初始化
首次访问先完成配置：
1. 薪资类型（月薪/时薪）、金额、税前/税后口径（默认税前）。
2. 每月标准计薪工作日、每周工作日、上午/下午作息、午休及是否带薪；后续支持不同日排班及补班/假期例外。
3. 加班有无额外工资、倍率或时薪、发薪日、通知偏好。
4. 检查工资预估并确认；确认后才保存到本地。可在设置重新修改。

## 计算原则
- 固定月薪的每日基本工资 = 月薪 ÷ 用户设定的每月标准计薪工作日。
- 每秒基本工资 = 当日基本工资 ÷ 当日标准计薪总秒数。
- 时薪模式按用户选择的带薪时段计入。
- 午休是否计薪由用户决定。固定月薪模式下，勾选带薪午休不额外增加每日固定基本工资，只改变其分配的计薪时段。
- 加班收入单独累计；厕所、摸鱼、学习期间对应收入是本日收入的一部分，不可重复加算。
- 以时间戳和工作时段交集计算，处理刷新、跨时段、休眠、跨天；显示时才四舍五入；历史记录避免在薪资修改后无提示回溯重算。
- 展示收入为模拟值，非实际工资单。

## 主要状态（7种）
1. 工作：按作息自动进入，计薪。
2. 厕所：手动开始/结束；活动持续期间显示「带薪拉屎中」；结束弹出时长、对应收入和随机搞笑文案。
3. 摸鱼：手动开始/结束，同样结算。
4. 午休：按时间自动进入，提醒和午休倒计时，是否计薪由设置决定。
5. 下班冲刺：下班前 30 分钟自动提醒，不抢占正在进行的手动活动。
6. 下班：按时间进入，停止正常计薪，触发一次性日结。
7. 学习：手动开始/结束，统计学习时长和工作时段内对应的模拟收入；非工作时间学习可以计时但默认不计薪。

补充：已按用户要求取消「带薪开会」；老板模式是隐私展示模式，不属于工作状态。手动活动同一时间只能有一个，切换需结束上一个并保存记录。

## 时间提醒示例（可自定义）
08:25 上班预警；08:30 开始工作；11:55 干饭预警；12:00 午休开始；13:25 午休结束预警；13:30 下午开工；17:30 下班冲刺；18:00 下班结算。仅在用户允许时弹系统通知。普通网页关闭后不保证系统级准点提醒。

## 活动结算与趣味内容
- 厕所/摸鱼/学习：点击图标开始→持续显示状态与计时→清晰的结束按钮→随机恭喜文案＋时长＋该时段模拟工资→保存并回到应有状态。
- 厕所示例：「🎉 恭喜你！成功完成一次由公司全额赞助的厕所之旅！」
- 文案按工作状态、阶段、时间等选取，支持幽默程度设置或关闭。
- 基础成就包括：厕所印钞机、摸鱼宗师、学习狂魔、干饭特种兵、牛马生存王；避免鼓励超时工作、久坐或刻意延长厕所时间。
- 下班结算展示基本工资、加班工资、活动时长、学习统计、成就，不重复弹出。

## 隐私、安全和响应式硬要求
- 默认无需账号，不收集姓名、公司或手机号，不主动上传工资及活动数据。
- 对输入与恢复的本地数据做类型、范围、时间顺序校验；不通过 `v-html` 或动态脚本执行用户输入。
- 浏览器本地存储不等于加密存储，不能保存密码和密钥。提供后续的数据导出、清除和迁移策略；不同浏览器域/桌面端存储不自动互通。
- 老板模式隐藏工资、活动状态、相关提醒内容，但不删除原始记录。
- 页面适配桌面、平板、手机；小组件适配约 400×100 px 和 Windows 高 DPI；不要出现无意义的横向滚动，重要按钮可键盘操作，支持减少动画。
- 每次更改都要检查安全、页面适配、功能回归；未经同意不删已确定功能。
